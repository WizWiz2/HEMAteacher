# Manuscript theme

Theme-only adaptation of the supplied fencing-manual reference. Existing routes, responsive training layout, camera and anatomy calibration remain intact.

- PT Serif for Russian body text, Cormorant Garamond for headings, UnifrakturMaguntia for the Latin masthead and master-cut titles. Self-hosted WOFF2, licenses in public/fonts.
- Generated parchment, transparent ornamental frame, masthead fencers and five articulated engraving parts. WebP assets in public/theme; prompts in docs/design.
- Target illustration follows existing landmark endpoints and facing. It is a stylized diagram, not a historical source or new definition of fencing technique.
- Colors: paper #f1e2ce, ink #281d14, rubric #a52b22. Existing red/green coaching indicators retained.
- Theme overrides live in manuscript-theme.css. No remote font or image service is needed at runtime.
